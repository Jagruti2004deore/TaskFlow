# TaskFlow — Team Task Management API

TaskFlow is a Python backend project for managing tasks through a REST API.

## Features

- User registration and login
- Password hashing
- JWT-based authentication
- User-specific task ownership
- Create, list, search, and filter tasks
- Update task status
- Delete tasks
- Pagination
- SQLite database
- Automated tests with pytest

## Tech Stack

- Python
- FastAPI
- SQLite
- PyJWT
- pwdlib
- pytest
- Uvicorn
